# COUNT · ผลสุ่มนับยาประจำปี

Dashboard ภาษาไทยสำหรับผลนับยา PHA01, PHA02 และ PHA04 รอบ 29 กันยายน 2569

เว็บไซต์: https://Senokot28.github.io/INVstock_KPHpharmacy/

เปิด `index.html` ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม ใช้งานออฟไลน์ได้ ไม่มี CDN หรือการเชื่อมต่อฐานข้อมูลจากหน้าเว็บ และฝังผลนับจริงไว้ในไฟล์ตามที่เจ้าของข้อมูลกำหนด

## การใช้งาน

- ภาพรวม: จำนวนที่นับ ความถูกต้อง มูลค่าผลต่างขาด/เกิน กราฟแยกหน่วยจ่ายยา Top 10 และตารางกลุ่มยา
- กรองแผนก กลุ่มยา เหตุผลที่นับ และ VEN; เลือกเกณฑ์ตรงทุกหน่วยหรือ ±2%
- รายการยา: ค้นหาชื่อ รหัส หรือตำแหน่งวางยา และกรองรายการที่ต้องตรวจสอบ
- เปรียบเทียบ PHA01/PHA04 ข้างกัน; เลือกเฉพาะยาที่ผลต่างไม่เป็นศูนย์ทั้งสองแผนก
- ส่งออก CSV ตามมุมมอง/ตัวกรองปัจจุบัน หรือพิมพ์รายงาน
- เปิด “จัดการข้อมูล” เพื่อเลือก CSV ใหม่ในเครื่อง การเลือกไฟล์ไม่อัปเดตเว็บไซต์ให้ผู้ใช้อื่น

## ข้อมูลที่เผยแพร่

ผลนับจาก `count_PHA01.csv`, `count_PHA02.csv`, `count_PHA04.csv` รวม 300 รายการยา–แผนก คำนวณ M × F + N และหัก J ใหม่ทุกครั้ง

CSV ล่าสุดมีผลนับ PHA04 ครบ 100 รายการแล้ว ขณะที่บันทึก CLAUDE.md ระบุ 99 ซึ่งเป็นสรุปก่อนหน้า ความถูกต้องตรงทุกหน่วย: PHA01 59%, PHA02 45%, PHA04 49%; รวม 153/300 = 51%

ราคาและ VEN อ้างอิง `Random Year.csv` โดยเลือกเฉพาะรหัสที่ใช้ในผลนับ ราคา/หน่วย = STD_PRICE3 ÷ PACK_RATIO ข้อมูลราคาครอบคลุม 258/300 รายการ (PHA01 100, PHA02 58, PHA04 100) อีก 42 รายการไม่มีราคา จึงไม่รวมในยอดเงินหรือตัวหารมูลค่า Dashboard ระบุความครอบคลุมตามตัวกรองเสมอ ไม่ตีราคาที่ขาดเป็นศูนย์

คอลัมน์ O ว่างคือยังไม่นับ; O = 0 คือนับแล้วได้ศูนย์ ข้อมูลยังไม่นับไม่รวมในตัวหาร เกณฑ์ ±2% เทียบค่าสัมบูรณ์ยอดระบบ ยอดระบบศูนย์ต้องนับได้ศูนย์ ส่วน Fentanyl/Morphine/Midazolam ใช้เกณฑ์ตรงทุกหน่วยตามข้อกำหนดโครงการ

ยอดระบบเป็น snapshot ก่อนนับ ผลต่างอาจเกี่ยวกับรับ–จ่ายระหว่างนับ ต้องตรวจ CARD_SUBS ก่อนยืนยันสาเหตุ ราคาที่ใช้เป็นราคาอ้างอิง ไม่ใช่ต้นทุนรายล็อต ไม่ใช้ ABC และไม่แก้ยอดฐานข้อมูล

## แก้ไขและสร้างไฟล์ใหม่

ต้นฉบับโค้ดอยู่ใน `src/` ไฟล์ CSV ต้นฉบับเก็บในเครื่องและไม่เขียนทับ

```powershell
python build.py
npm ci
npm test
npm run test:browser
```

`build.py` อ่านใบนับจากโฟลเดอร์นี้และราคา `../Random Year.csv` แล้วสร้าง `index.html` ใหม่ พร้อม hash ของแหล่งข้อมูลใน `build-manifest.local.json` การทดสอบเบราว์เซอร์ใช้ Microsoft Edge ที่ติดตั้งในเครื่อง

หากมีไฟล์ราคาครบทุกตัว ใช้หัวคอลัมน์ `WORKING_CODE,VEN,ราคา/บรรจุ(STD_PRICE3),PACK_RATIO` แล้วสั่ง:

```powershell
python build.py --master prices.local.csv --price-source "ราคาอ้างอิงจากไฟล์ราคาที่ตรวจสอบแล้ว"
```

สร้างหน้าเว็บแบบไม่มีข้อมูลฝังได้ด้วย `python build.py --empty` (การทดสอบ snapshot จริงจะใช้ไม่ได้กับโหมดนี้)

## เผยแพร่ GitHub Pages

ตั้ง Settings → Pages → Deploy from a branch → `main` → `/ (root)`

หลังสร้างไฟล์และทดสอบแล้ว commit/push `index.html` พร้อมโค้ดที่เปลี่ยน การ push `main` จะอัปเดตเว็บไซต์ ใช้ `.nojekyll` เพื่อส่งไฟล์ HTML โดยตรง

อ้างอิง: [GitHub Pages publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

ไม่อัปโหลด MDB, ข้อมูลเชื่อมต่อฐานข้อมูล, CLAUDE.md, ไฟล์สำรอง หรือไฟล์ราคาเต็มไปกับเว็บไซต์
